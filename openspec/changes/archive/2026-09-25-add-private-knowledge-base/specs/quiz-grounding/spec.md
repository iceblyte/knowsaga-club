# Spec Delta

## MODIFIED Requirements

### Requirement: 有资料时，题目必须以资料为唯一事实依据

当出题获得了取材资料时，题干、选项、正确答案与讲解的内容必须（MUST）能在资料中找到依据；
模型自身的记忆与资料冲突时，**以资料为准**。

取材资料有两类来源：**公开网页**（关键词检索所得、或按用户给的网址读取所得）与
**用户自己的知识库**（用户上传并解析入库的文档片段）。两类都必须（MUST）被当作事实依据，
且**用户自己给的资料优先于公开来源**：知识库文档、用户输入里的网址，都属于「用户自己给的」。
反过来说，断言「资料里没有这个知识点」时不得（MUST NOT）把用户自己的资料排除在「资料」之外。

#### Scenario: 资料覆盖了该概念的权威口径
- **WHEN** 资料中给出了某概念的定义、组成部分或适用边界
- **THEN** 题目与讲解按资料的口径表述，不出现资料中不存在的具体数据、时间、版本号或结论

#### Scenario: 模型记忆与资料冲突
- **WHEN** 资料对某事实的表述与模型自身记忆不一致
- **THEN** 采用资料的表述

#### Scenario: 检索到的资料与学习需求无关
- **WHEN** 公开检索命中了内容，但资料与该次学习需求所指的概念无关
- **THEN** 这批资料被**忽略**，出题按「没有资料」的情形处理 —— 宁可不使用资料，也不把无关内容强行套进题目

#### Scenario: 用户自己给出的资料不适用「无关即忽略」
- **WHEN** 资料来自用户输入里给出的网页链接
- **THEN** 不得以「与输入无关」为由忽略它 —— 用户给出的资料就是他要学的东西；
  忽略它等于回到「贴了链接却没被读」

#### Scenario: 知识库片段属于「用户自己给的资料」
- **WHEN** 一次召唤指定了知识库，且检索命中了该库的文档片段
- **THEN** 这些片段按「用户自己给的资料」对待，不适用「与输入无关即整体忽略」

#### Scenario: 知识库与公开来源冲突
- **WHEN** 知识库片段与公开检索结果对同一事实的表述不一致
- **THEN** 以知识库片段为准 —— 它是用户自己指定的学习材料

#### Scenario: 知识库检索无命中时不假装有依据
- **WHEN** 指定了知识库但检索没有拿到任何片段
- **THEN** 出题按「没有资料」的情形处理，不得让题目或讲解暗示「依据了你的资料」
