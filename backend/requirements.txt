# 《知拾冒险社》后端依赖
# 版本均为 2026-09-16 实测最新稳定版，勿随意升级（升级前请先跑 pytest）

# --- Web 框架 ---
fastapi==0.141.1
uvicorn[standard]==0.53.0
pydantic==2.13.5
pydantic-settings==2.15.0
# 头像上传走 multipart/form-data。FastAPI 的 UploadFile/File 依赖它，
# 缺失时**在路由注册阶段**就报 "Form data requires python-multipart"，
# 表现为整个应用起不来，而报错信息不会告诉你要装哪个包。
python-multipart==0.0.32

# --- 数据库（用户系统）---
# 同步 SQLAlchemy + PyMySQL：本项目的接口全是同步 def，出题/报告链还跑在
# ThreadPoolExecutor 后台线程里，同步驱动在两边都能直接用，少一层事件循环桥接。
# 想换异步只需把 DSN 改成 mysql+aiomysql://（代码零改动），届时再加 aiomysql。
sqlalchemy==2.0.54
pymysql==1.2.3
# MySQL 9.x 已移除 mysql_native_password，账号默认 caching_sha2_password，
# 因此 cryptography 是**必需**依赖（不是可选），否则认证会直接失败。
cryptography==50.0.1

# --- 登录态 ---
pyjwt==2.14.0

# --- 时区数据 ---
# Windows 没有系统 IANA 时区库，ZoneInfo("Asia/Shanghai") 会抛
# ZoneInfoNotFoundError。业务时区（连续天数 / 错题到期 / 看板按天分组）
# 依赖它，所以是运行依赖而不是测试依赖。
tzdata==2026.4

# --- LLM ---
langchain==1.4.0
langchain-core==1.6.3
langchain-openai==1.6.2
# 联网取材（关键词检索 + 按 URL 抓整页）。2026-09-22 实测最新稳定版 0.2.18。
# 为什么用它而不是自己拼 HTTP：官方把工具名、工具描述、参数 args_schema 与错误语义
# 都做好了，而模型正是靠 description 与参数说明决定怎么用工具的 —— 手抄一份只会与上游漂移。
# 为什么不用 tavily-python 官方 SDK：它是纯 HTTP 客户端，没有 LangChain 工具契约，
# args_schema 与 description 仍要自己写，等于少了一半好处还多一层依赖。
# 版本约束核对（升级前必须重跑 pytest）：
#   langchain-tavily 0.2.18 要求 langchain-core>=1.2.11,<2.0.0 与 langchain>=1.0.0,<2.0.0，
#   与本文件的 1.6.3 / 1.4.0 兼容 —— 安装时**不会**改动这两个既有版本。
#   它还会带入 requests 与 aiohttp 两个传递依赖（上游包的既定选择，我们不改写）。
# ⚠️ 该包内部 `_utilities.py` 的 requests.post **没有传 timeout**，网络黑洞会无限等待；
#    调用侧必须自己外包超时（见 app/llm/search/agent.py 的 D12 说明）。
langchain-tavily==0.2.18

# --- HTTP 客户端（微信接口 / 测试用）---
# 联网取材不走它：Tavily 侧由 langchain-tavily 自带的 requests / aiohttp 负责。
httpx==0.28.1

# --- 测试 ---
pytest==9.1.1
pytest-asyncio==1.4.0
pytest-cov==6.2.1
